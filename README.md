# KInceron的知识库

> 一个会和我一起生长的个人 Wiki。

这里不是一个追求完整答案的资料库，而是一个带着个人气味、可以慢慢长大的入口。

## Now

这一块只回答一个问题：**我最近在做什么。**

它是首页上的轻量行动区，用来记录最近正在推进的事、反复出现的主题，以及当前阶段真正占据我注意力的东西。这里不追求面面俱到，一段话就够，重要的是能在以后回看时重新认出自己当时处在什么阶段。

- [Now / 我最近在做什么](wiki/now.md)

## Timeline

时间线是总索引，用来回看人生阶段、转折和迁移。

它不负责承载全部内容，而是把散落在不同页面里的生活、学习、工作和思考重新串起来，帮我看见自己是怎么一步步走到这里的。

- [Timeline / 人生时间线](wiki/timeline.md)

## Wiki 系统

这套结构参考了 Karpathy 提出的 LLM Wiki 思路：把知识库当作一个可以持续维护、持续更新的 Markdown 仓库。原始材料保留下来，提炼后的内容沉淀进 Wiki，索引、日志和结构约定则帮助它在时间里继续长大。

- [索引 / Index](wiki/index.md)
